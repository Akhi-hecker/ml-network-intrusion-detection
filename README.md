## Abstract
This project presents a performance-driven Network Intrusion Detection System (NIDS) utilizing a Sparse Autoencoder (SAE) for robust feature extraction and a Soft Voting Ensemble for state-of-the-art anomaly classification. Targeting real-time SOC environments, the architecture efficiently processes network traffic, minimizing noise and maximizing threat detection accuracy using the CICIDS2017 dataset.

## 1. Introduction
With the rapid expansion of network infrastructures, intrusion detection systems are critical for identifying malicious activities. This project proposes an advanced approach integrating deep learning representations with ensemble tree decision-making to deliver high-accuracy classification across binary and multiclass scenarios.

## 2. Dataset and Preprocessing
The evaluation utilizes the CICIDS2017 dataset, which encompasses over 2.5 million network traffic samples and 52 distinct features. The dataset undergoes rigorous preprocessing and normalization to ensure feature consistency prior to dimensionality reduction and classification.

## 3. System Architecture
The proposed pipeline operates in two distinct phases: feature compression and classification.

### 3.1 Feature Extraction: Sparse Autoencoder (SAE)
The SAE is tasked with eliminating noise and reducing dimensionality, transforming raw network packets into a concentrated latent representation.
- **Network Topology:** 52 (Input) → 45 (Hidden) → 42 (Latent Space) → 45 (Hidden) → 52 (Output)
- **Activation Function:** ELU
- **Hyperparameters:** 50 Epochs, Batch Size of 256
- **Optimization Strategy:** Mean Squared Error (MSE) coupled with L2 Regularization (λ=0.0001) and KL-Divergence penalty (β=0.1, ρ=0.05).

### 3.2 Classification: Multi-Tier Ensemble
The latent features generated by the SAE are propagated to an ensemble framework designed for final classification.
- **Random Forest (Baseline):** Configured with 10 estimators, this module establishes a foundational baseline derived from traditional methodologies.
- **XGBoost:** An advanced gradient boosting extension leveraging 100 trees, evaluating with a learning rate of 0.1 and a maximum depth of 6 for high-precision learning.
- **Soft Voting Ensemble:** The primary proposed architecture fuses probabilistic outputs from both the Random Forest and XGBoost classifiers, maximizing detection reliability.
